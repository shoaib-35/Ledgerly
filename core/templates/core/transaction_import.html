Import format

Use these exact columns

transaction_idOptional. Keep it when re-importing an export; existing IDs are skipped. dateRequired. Use YYYY-MM-DD, for example 2026-09-26. transaction_typeRequired: EXPENSE, RECEIVED, INCOME, BONUS, EXTRA, CARD_PAYMENT, or TRANSFER. amountRequired positive amount, for example 1250.00. Do not include the currency symbol. descriptionRequired text describing the transaction. statusOptional: ACTIVE or VOIDED. Blank means ACTIVE. person_id / person_nameUse the ID for exact matching, or the exact person name. Expense and Received transactions require a person. account_id / account_nameNormal transactions use these for the affected account. Use IDs when available. source_account_id / source_account_nameUsed by TRANSFER and BANK_ACCOUNT card payments. destination_account_id / destination_account_nameRequired for TRANSFER. This is the receiving account. payment_sourceRequired for CARD_PAYMENT: BANK_ACCOUNT or CASH. created_atOptional ISO datetime. Exported files include it to preserve same-day transaction ordering.

Important: account and person names must match exactly if you do not provide their UUID. If two accounts or people have the same name, use the corresponding ID from an exported Ledgerly file. Archived accounts and people cannot be used for new imports.
